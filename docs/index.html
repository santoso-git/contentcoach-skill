Install the skill

One file in your agent's skills folder, and a key in your shell. You get the key from whoever sent you this page.

1Key

Put your key in your shell

In ~/.zshrc on a Mac or ~/.bashrc on Linux. Never in a project and never in git. Open a new terminal and restart your editor afterwards.

export CONTENTCOACH_KEY="your-key"
2Agent

Tick your agent

# Cursor reads skills from ~/.cursor/skills
mkdir -p ~/.cursor/skills/contentcoach
curl -fsSL https://raw.githubusercontent.com/santoso-git/contentcoach-skill/main/contentcoach/SKILL.md -o ~/.cursor/skills/contentcoach/SKILL.md

Restart Cursor. The skill is used in Agent mode. Run the same line again to update.

3Ask

Ask for a picture or a clip

Make a 16:9 blog header about remote work: a small desk in a Nordic cabin, rain outside.

Animate that image: a slow push-in, rain running down the window. Five seconds.

Before a clip runs, the skill tells you the model, the length and the price, and waits for your yes. Everything lands in generations/ in your open project, next to a .json that records the prompt, the model and the cost.

How the skill behaves

Printed on the back of the envelope, so nobody is surprised.

One personal key

The skill needs a ContentCoach key, handed out personally. There is no sign-up and no provider account. If someone sent you this page, they have yours.

Video is quoted first

A clip costs roughly ten times an image. The skill shows you the model, length, resolution and price before every clip, and runs only on your yes.

A daily budget

Each key has a budget in US dollars per day that resets at midnight Stockholm time. The skill checks what is left, for free, before it spends anything.

Drafts first

Everything is made at 1K unless you ask. Ask for 2K or 4K once you have a favourite.

Real files, not descriptions

For a logo, a product or a face, give the agent the file. A logo described in words comes back wrong every time.

Where your data goes

The skill sends prompts and reference images to the ContentCoach API, which passes them to a model provider: Kie AI, fal.ai, WaveSpeed or Google. Reference images sit at a public address so the provider can fetch them; upload nothing you would not want reachable. Finished images and clips are not kept, and their link expires within hours, so the skill downloads them straight away.
