# Skill homepage

Scope: the one-page public homepage for the ContentCoach client skill, served by
GitHub Pages from `docs/` in santoso-git/contentcoach-skill, at skill.contentcoach.se. Visitor mode: Persuade.

Audience: people who work in Cursor, Codex or Claude Code and will create their
own key at Kie AI or fal.ai. Job: understand what they get, get a key, pick
their agent, copy one command. Proof: seven real images and one clip made with the same models and providers on
26 Sep 2026. Constraints: static, very simple, English, the user's own provider keys,
no invented claims.

## Direction contract

THESIS: The page is a photo lab's processing envelope. You write the order (a
sentence), tick a size, hand it in at your counter (your agent), and prints come
back. It refuses the category default: a dark dev-tool hero around a fake
terminal.

OWN-WORLD: Envelope stock in signal yellow owning whole bands of the page, one
black printing ink, a lab red reserved for ticked boxes and the pressed state
(raise, from Memphis showroom: one colour reserved for the pressed control).
Ruled fill-in lines, square tick boxes, perforation rows, docket numbers. Prints
are white-bordered photographs with lab back-print beneath: frame, model, size,
cost. Depth only by flat sheets overlapping, never by glow or blurred halo
(raise, from Łowicz papercut: depth made only by overlap). Condensed grotesk for
the envelope's printed headings, a plain sans for body, mono for commands and for
what the lab's machines print: the typed order line and the back-print on each
print (adaptation recorded after the finish review).

STORY: Your own Kie or fal key; your agent makes images with several models; here are real
prints with what each cost; pick your agent, copy one line; know what it costs
and where the data goes.

FIRST VIEWPORT: Full-width yellow envelope. Left two-thirds: the product name
set huge and condensed, one line on what it does, then the order form with the
example sentence typed on the ruled line and the 1K / 2K / 4K boxes with 2K
ticked (the size the example print was actually run at). Right third: three prints fanned half out of the envelope mouth. The
primary action, "Choose your agent", sits under the form; "Read the skill" is
the quiet second.

FORM: film-lab processing envelope, candidate 7 of 7, seed e4765e4c.
Signature interaction: the drop-off row, one unbroken tick row of Cursor, Codex,
Claude Code and No install (raise, from drum-machine step row: one line that
scales, never wraps); ticking a box reprints the command beneath it, fully
keyboard operable (raise, from ANSI nightboard: complete keyboard operation).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
